# Sigma v0.1.0 Release Readiness Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a professional first formal release with simple CLI UX (`sgm expense/income/...`), first-run setup (`sgm start`), and automated PyPI publishing from GitHub tags.

**Architecture:** Keep the current layered monolith and add a thin CLI experience layer that maps flat commands to existing domain/application logic. Introduce a persisted user config for first-run setup and UI preferences, while keeping the database path internal/default-only. Add repository release automation and contributor ergonomics (CI, Makefile, templates) without expanding domain scope.

**Tech Stack:** Python 3.12, Typer, Rich, SQLite, pytest, Ruff, GitHub Actions, PyPI Trusted Publishing

  push:
    tags: ["v*"]
jobs:
  build:
    runs-on: ubuntu-latest
    permissions: { id-token: write, contents: read }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: python -m pip install --upgrade build
      - run: python -m build
      - uses: pypa/gh-action-pypi-publish@release/v1
