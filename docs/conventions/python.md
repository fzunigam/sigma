# Python Conventions

## Runtime and tooling
- Target Python version is **3.12**.
- Keep code Ruff-clean with `python3.12 -m ruff check .`.

## Typing and API shape
- Add explicit type hints for function parameters and return values.
- Use `Enum` for closed value sets (for example `AccountType`, `MovementType`).
- Prefer `Path` over raw path strings at boundaries that touch the filesystem.

## Domain modeling
- Use dataclasses for domain entities/value objects.
- Use `@dataclass(frozen=True)` for immutable value objects/snapshots.
- Validate invariants in constructors (`__post_init__` or factory methods) and raise `DomainValidationError` for business rule violations.
- Monetary values are CLP integer pesos; reject non-integers and non-positive amounts.

## Layering and dependencies
- Keep layered boundaries clear: `domain` should not depend on `infrastructure` or CLI modules.
- Put orchestration logic in `application` use cases; keep repository and DB concerns in `infrastructure`.
- Keep CLI commands focused on input handling, invoking use cases/repositories, and formatted output.

## Time and persistence
- Use timezone-aware datetimes (UTC where generated by the app).
- Persist datetimes in ISO-8601 text form in SQLite.
